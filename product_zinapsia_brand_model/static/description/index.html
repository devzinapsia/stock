Zinapsia Product Brand and Model

This module adds a configurable Brand catalog and a free-text Model field to products.

  • Brand is a dedicated, configurable catalog managed from Inventory > Configuration > Brands. It is searchable, filterable, groupable, and available as an optional column in the product grid.
  • Model is a free-text field, available as an optional column in the product grid.

Technical model and field names are namespaced under zinapsia to avoid colliding with the unrelated product.brand model shipped by other modules.
