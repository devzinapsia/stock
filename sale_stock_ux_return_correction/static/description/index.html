Sale Stock UX Return Correction

Restores the native stock return wizard behavior for purchase (incoming) returns, which sale_stock_ux blocks by default with a "You cannot create exchanges for return lines marked to refund" error.

  • Hides sale_stock_ux's explanatory banner and the "Para Abonar (actualizar OC/OV)" column on the return wizard.
  • Lets the native "Devolución para cambio" (Create exchanges) action run on purchase order returns.
  • Leaves sale order returns and exchanges untouched, since sale_stock_ux's exchange tagging still drives qty_delivered accuracy there.
  • Restores sale_stock_ux's original view on uninstall.
